# Meridian Flow — Product Overview

Meridian Flow is a project management and team collaboration platform built by
Meridian Cloudworks, Inc., founded in 2019 and headquartered in Austin, Texas.
The product launched publicly in March 2021.

## Core modules

- **Boards** — Kanban-style task boards with custom workflow states.
- **Timeline** — Gantt-chart style scheduling with dependency tracking.
- **Docs** — Collaborative documents linked directly to tasks and projects.
- **Automations** — Rule-based triggers (e.g., "when a task moves to Done, notify the requester").

## Supported integrations

Meridian Flow integrates natively with Slack, Microsoft Teams, GitHub, GitLab,
and Google Calendar. A public REST API and webhook system are available on the
Business and Enterprise plans.

## System requirements

Meridian Flow is fully web-based (Chrome, Edge, Firefox, Safari — latest two
major versions of each). Native desktop apps exist for Windows and macOS. A
mobile app is available for iOS and Android.
